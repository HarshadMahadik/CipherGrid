DEPLOYMENT GUIDE

Installation & Hosting

CipherGrid is a static HTML5 template that requires no server-side compilation, build tools, or database to run.

1. Local Preview Testing

You can run CipherGrid instantly using any lightweight local static server:

# Option A: Python 3 built-in server
python -m http.server 8080

# Option B: Node.js npx serve
npx serve .

# Option C: VS Code Live Server
Right click index.html -> "Open with Live Server"

Then navigate to http://localhost:8080 in any modern browser.

2. Web Server Production Hosting

To deploy on production web servers, copy the entire contents of the SOURCE folder to your webroot:

  • Apache HTTP Server: Upload all files to /var/www/html/ or public_html/.
  • Nginx: Point your root directive in /etc/nginx/sites-available/default to the directory.
  • Netlify / Vercel / Cloudflare Pages: Simply connect your Git repository and set publish directory to . (root). No build command required!
  • GitHub Pages: Push to a GitHub repository, enable GitHub Pages from main branch.
