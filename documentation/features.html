INTERACTIVE LOGIC

Features & Script Architecture

Detailed review of all interactive ES6+ components embedded in assets/js/main.js.

1. Live Threat Radar (Canvas Visualizer)

The interactive radar located on index.html is rendered dynamically via the HTML5 <canvas> API. It performs a continuous 360-degree sweep with conic gradients and displays pulsing adversary blips.

You can customize the blips or add your own coordinates in assets/js/main.js under the blips array:

const blips = [
  { r: radius * 0.45, theta: 0.8, label: "CVE-2026-1049", type: "critical" },
  { r: radius * 0.72, theta: 2.3, label: "BOTNET-SCAN", type: "high" }
];

2. Security ROI & Risk Assessment Calculator

The interactive slider on the homepage recalculates breach risk exposure and annual savings in real time based on endpoint count and industry multipliers.

The calculation formula can be fine-tuned in assets/js/main.js:

const baseBreachRisk = endpoints * 320 * industryRisk * complianceMultiplier;
const estimatedSavings = baseBreachRisk * 0.78; // 78% mitigation

3. CVE Advisory Database Search & Filter

Instant client-side text filtering and severity level button toggles on threat-lab.html. No page reloads or database round-trips required.

4. Transparent Pricing Switcher

The Monthly / Annual switcher on pricing.html updates all pricing values dynamically reading from data-monthly-price and data-annual-price HTML attributes.
