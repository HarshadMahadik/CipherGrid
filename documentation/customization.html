Customization Guide

How to customize colors, typography, logos, and form handling for your client or project.

1. Customizing Design Tokens (Colors & Theme)

All colors, shadows, and geometry are centralized in assets/css/style.css under :root. Simply modify these variables to match your client's brand palette:

:root {
  /* Change brand primary color */
  --cg-primary: #2563eb;        /* Main brand blue */
  --cg-primary-hover: #1d4ed8;  /* Hover state */
  --cg-accent: #38bdf8;         /* Cyan accent / highlight */
  
  /* Change background surfaces */
  --cg-bg-main: #060b17;        /* Body background */
  --cg-bg-secondary: #0b1120;   /* Secondary card surface */
}

2. Replacing the Brand Logo

The logo is located in assets/images/logo/logo.svg. You can replace this SVG directly with your company's SVG, or replace it with a PNG image by modifying the <img> tag in the header and footer:

<a class="navbar-brand" href="index.html">
  <img src="assets/images/logo/your-logo.png" alt="Company Name" width="200" height="40">
</a>

3. Connecting Forms to a Backend

By default, forms on contact.html, the newsletter bar, and the Request Demo modal operate in demonstration mode with full HTML5 client-side validation.

To connect to a live backend, choose one of these popular approaches:

  • PHP Mailer: Create a sendmail.php script and set the form action="sendmail.php" method="POST".
  • Formspree / Formkeep / Basin: Set action="https://formspree.io/f/YOUR_FORM_ID" method="POST".
  • REST API / Node.js / Python Flask: Replace the demo handler in assets/js/main.js with a standard fetch('/api/contact', { method: 'POST', body: JSON.stringify(...) }).
