# Technical Specifications — CipherGrid Template

## Core Stack
- **Specification:** HTML5 (W3C Semantic Standards)
- **CSS Framework:** Bootstrap 5.3.3 + Custom CSS Tokens (CSS3 Variables)
- **JavaScript Standard:** ECMAScript 2020+ (Vanilla ES6+, Zero jQuery)
- **Iconography:** Bootstrap Icons 1.11.3 (Self-hosted WOFF2/WOFF)
- **Viewport Support:** 320px, 375px, 430px, 768px, 1024px, 1440px, 1920px

## Performance & Optimization
- Zero external render-blocking network calls
- Local WOFF2 font preloading and zero layout shifts
- Hardware-accelerated CSS transforms and canvas animations
- Total static bundle size < 2.5 MB (including all documentation and vendor libraries)

## Browser Compatibility
- Google Chrome: Latest 3 versions (Windows, macOS, Linux, Android, iOS)
- Microsoft Edge: Latest 3 versions
- Mozilla Firefox: Latest 3 versions
- Apple Safari: Latest 3 versions (macOS, iOS)
